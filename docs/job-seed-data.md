# 채용공고 시드 데이터

`apps/backend/app/jobs/repository.py`의 목 데이터를 현실감 있게 보강하기 위한 시드.
회사 20개(`_COMPANIES`) × 직무 8개(`_ROLES`)를 조합해 공고를 생성한다.

- 출처: 공개된 회사/직무 일반 정보를 참고해 **생성**한 데이터. 실제 채용공고 verbatim 복사 아님.
- 파싱 규약: 회사는 `_COMPANIES`의 첫 원소(한글명)로, 직무는 `_ROLES`의 카테고리 키로 매칭.
- 조합 방식: 공고 본문 = **직무 JD 템플릿** + 해당 회사의 **강조 스킬**(있으면). `match_reason`은
  프로필 매칭 근거이므로 회사 도메인 키워드를 섞으면 자연스럽다.

## 3. 조합 가이드 (backend 참고)

- 공고 태그 = 직무 기본 태그 + (회사 강조 스킬 중 직무와 관련된 1~2개).
  - 예) 토스 × 백엔드 → `[Java, Spring, MSA, Kotlin, 정산 정합성]`
  - 예) 쿠팡 × 데이터 → `[Spark, Airflow, Python, 대규모 분산 시스템]`
  - 예) 네이버웹툰 × ML → `[PyTorch, MLOps, Python, 추천시스템]`
- `title` 예: `[토스] 백엔드 개발자 — 정산 시스템`
- `match_reason`은 프로필의 강점 + 회사 도메인 키워드를 연결(예: "결제 실패율 개선 경험이
  토스의 정산 정확성 요구와 통해요").
