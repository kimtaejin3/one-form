# 자소서 허브 실데이터 스냅샷

현재 시드 데이터는 임의의 공통 질문 모음이 아니라 2026년 상반기 삼성전자 신입사원 공고에서 확인한 4개 문항을 사용한다.

- 기업: 삼성전자
- 접수 기간: 2026-03-10 ~ 2026-03-17 17:00
- 문항: 지원동기·성장과정·사회이슈·직무역량
- 채용 시행 확인: [삼성전자 반도체 뉴스룸 2026년 상반기 공채 안내](https://news.samsungsemiconductor.com/kr/%EC%82%BC%EC%84%B1-2026%EB%85%84-%EC%83%81%EB%B0%98%EA%B8%B0-%EA%B3%B5%EC%B1%84-%EC%8B%A4%EC%8B%9C/)
- 문항 원문: [잡코리아 삼성그룹 자소서 항목](https://www.jobkorea.co.kr/company/1808899/keyword?C_Idx=171&Ort_Year=0&Page=9)
- 공고 확인일: 2026-08-01

채용 문항은 회사·직무·회차마다 바뀔 수 있다. 원문과 공고 링크를 확인하지 못한 회사는 임의로 시드하지 않으며, 다음 수집 단계에서 공고별 데이터로 추가한다. 현재 화면의 마감일은 해당 공고의 실제 접수 마감일이므로 지난 공고는 D+로 표시된다.
